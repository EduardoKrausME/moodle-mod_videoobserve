# Video Observation (mod_videoobserve)

Video Observation is a Moodle activity for systematic observation of video. Teachers define an observation sheet made of
reusable event types. Students watch the video and register each occurrence as a point in time or an interval,
optionally adding notes.

The activity automatically counts occurrences per event, tracks watched video segments and last position, renders a
timeline, produces a final observation sheet, and provides an aggregate report with event frequencies, time clusters,
per-student differences, average markings and comparison against a teacher reference answer.

Supported video sources: Moodle upload, direct video URL, YouTube and Vimeo. Uploaded videos and posters are served
through Moodle File API.

## Main workflow

1. Add a Video Observation activity and select the video source.
2. Open "Manage observation sheet" and create the event types students should identify.
3. Optionally open "Reference observations" and register the expected moments or intervals.
4. Students watch, register observations and review the generated sheet.
5. Teachers open the aggregate report to compare frequencies, time clusters, students and reference matches.

## Requirements

Moodle 4.4 or later.
